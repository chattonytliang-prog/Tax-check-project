# AI 助手文件与工具

普通对话和文件问答使用 AI SDK `ToolLoopAgent`，保留 DeepSeek 模型。助手可以连续检索原文、按页或工作表继续读取、查询企业数据，并生成真实文件。读取、分析、生成和下载文件自动执行，无需二次确认。

## 使用方式

- 将 PDF、Word、Excel、CSV、文本、JSON、PPT、图片或 ZIP 拖入对话框，也可以点击“上传文件”。现有解析器负责提取正文，扫描页和图片使用视觉识别。
- 直接提问，例如“核对这些文件中的手续费，并生成 Excel 明细和 Word 说明”。每次工具结果都会传回模型，助手据此继续调用工具或回答。
- 下载卡片显示在答复下方。继续说“读取上一版，补充说明后再生成一版”，助手会读取已生成文件并创建新文件，保留旧版。
- 未添加会话附件时，继续默认读取当前企业已归档的原件，包括初始化阶段保存的资料。

首期可生成 `.xlsx`、`.docx`、`.csv`、`.json`、`.txt`。Excel 和 Word 使用真正的 Office 文件格式。输出文件每份最多 8 MB；单轮最多 8 次模型调用、6 次生成操作，超出后可以继续追问。复杂任务的进度明细在答复完成后展示，当前接口仍返回完整 JSON。

## 环境与上线

1. 保持现有 `DB`（D1）和 `DEEPSEEK_API_KEY` 配置，`DEEPSEEK_MODEL` 可选，默认 `deepseek-flash`。Pages Functions 配置启用 `nodejs_compat`，本地 Workers 兼容性验证使用 `2026-07-15`。
2. 使用私有 R2 绑定 `ASSISTANT_MATERIALS_BUCKET` 或现有 `MATERIALS_BUCKET` 存储生成文件。
3. 在已有数据库迁移基础上执行 `migrations/0013_assistant_artifacts.sql`。旧环境还需要此前的会话、业务资料、AI 额度和附件迁移；不要跳过 `0012_assistant_attachments.sql`。
4. 按项目发布流程备份数据库并部署已提交的代码。本次开发不直接修改生产数据库或部署生产站点。

下载接口 `/api/assistant/artifacts/:id` 检查登录用户和所属对话，每次下载都验证权限。删除对话后文件记录同步删除，原下载地址失效；R2 对象的物理清理需沿用存储生命周期策略。每次模型请求单独计入已有每日额度，用户停止请求时取消后续处理。

文件工具只创建对话产物。企业数据写入继续走现有授权、校验和审计流程，未开放执行任意代码、修改规则或系统配置的工具。CSV 对公式标记做转义，Excel 将文本作为字面值写入。

## 验证

`npm test`、`npm run build`、`npm run lint`。集成测试通过真实 AI SDK 循环配合模拟模型响应，验证连续读取与生成、Office 文件内容、用户隔离、重试复用、追问改版、步数和额度限制。浏览器使用虚构资料检查上传、下载卡片及实际下载。另在本机 Workers 模拟环境中验证了 AI SDK → D1/R2 → Excel/Word 生成与下载的 5 轮调用。接入真实模型的效果还需在配置好密钥的预发布环境验收。
